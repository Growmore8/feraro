Semantic colour — and the one rule that matters

Accent is never a data colour. Amber marks the thing you can act on — the primary button, the live tab, the focus ring. It never encodes a price, a side or a P&L. Dealers read colour faster than they read digits, so a hue that sometimes means “buy” and sometimes means “click me” costs real money. Buy is blue and sell is red because that is the convention every FX trader already has in their hands; profit is green and loss is red because that is a different question from which way the order faced.

Every digit a trader compares down a column is IBM Plex Mono with font-variant-numeric: tabular-nums. Proportional figures make a price column ripple as it ticks, and a rippling column is one a dealer stops trusting. The engine's RejectReason variants are enum values, not sentences. Each maps to one line of trader-facing copy that says what happened and what to do — never the variant name, never an error code alone.

Toast notifications

Four severities, one shape: a 3px severity stripe, an icon, a bold line saying what happened, a detail line carrying the numbers, and an age. Anything the trader must act on gets one action link and nothing else. Fills and deposits auto-dismiss after six seconds; margin calls and rejections stay until dismissed, because a trader who missed one has a real problem.

Four money operations, never blurred together
Deposit Real money in. Increases balance and withdrawable funds. Withdrawal Real money out. Blocked when it would push margin level below stop-out. Credit Bonus. Counts toward margin, cannot be withdrawn, and is removed on the first withdrawal. Shown as its own line beside balance, never folded into it. Debit Correction out. Always carries a reason that reaches the client statement.
One convention to settle before build

This system uses buy = blue and sell = red, which is what MT4 trained most of the market on. Some platforms run it the other way round. It is a single token pair, so it can be flipped globally or made a per-trader preference — what it must never be is inconsistent between the desktop, mobile and dealer screens.
